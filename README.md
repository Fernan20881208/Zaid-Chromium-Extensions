# Zaid Chromium Extensions

Experimental Chromium Android fork focused on adding Chrome extension support.

## Goals

- Chromium modern base
- ARM64 Android build
- chrome://extensions support
- CRX loading
- Manifest V3 support
- Tampermonkey compatibility

## Build

The project uses GitHub Actions to prepare the Chromium build environment.
